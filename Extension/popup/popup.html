Safience Sync

Bookmarks, pinned and open tabs, through your iCloud

This copy of the extension has no CloudKit API token yet.

  1. In CloudKit Console, open iCloud.net.taehee.safience › API Access › API Tokens, and add one.
  2. Set its sign-in callback to URL:
  3. Put the token in config.js and reload the extension.

Sign in with the Apple Account you use on your iPhone or iPad. Safience keeps nothing anywhere else.

Pair this profile with a space

Its bookmarks bar becomes the space's bookmarks, and its pinned tabs the space's. Both sides keep what they have.

Another computer with this Chrome profile syncs its bookmarks; Chrome Sync brings them here.
