## Validation safety

[Release/update-test.sh](../Release/update-test.sh) verifies both generated app bundle IDs and embedded absolute data roots before launching an updater fixture. The test bundle uses its own defaults/WebKit namespace and an explicit `SAFIENCE_DATA_ROOT`. That workflow was syntax/plist/source checked here; an actual automatic update was not run by this agent. Real browser data, production defaults and real CloudKit accounts were not used for this ledger's checks.
